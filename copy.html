Код сервера «Server»

Нажмите «Скопировать» у файла — код скопируется целиком. В Apps Script откройте файл с тем же названием, выделите всё (Ctrl+A), вставьте (Ctrl+V), 💾 Сохранить.

Проще всего: удалите все старые файлы, кроме «Не трогать», создайте один файл «Server» и вставьте в него первый пункт. Остальные пункты нужны, только если хотите оставить файлы по отдельности.

Файл «Не трогать» не меняйте. Порядок файлов в Apps Script должен остаться таким же, как здесь.
  1. Замените все файлы по списку (зелёные — уже скопированы).
  2. 💾 Сохранить.
  3. «Начать развёртывание» → «Управление развёртываниями» → ✏️ → Версия: «Новая версия» → «Развернуть».
