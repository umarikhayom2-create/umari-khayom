Совет: переименуйте проекты (нажмите на «Проект без названия» вверху): чат → «Сайт — ЧАТ», основной → «Сайт — ОСНОВНОЙ».
  1. Нажмите кнопку выше — появится «Скопировано ✓».
  2. Откройте проект чата (идентификатор AKfycbxH7G72…). Слева у файла с кодом нажмите ⋮ → Удалить.
  3. Нажмите + рядом с «Файлы» → Скрипт → назовите server.
  4. В пустом окне подержите палец → Вставить → 💾.
  5. Начать развёртывание ▾ → Управление развёртываниями → ✏️ → Версия: Новая версия → Развернуть.
